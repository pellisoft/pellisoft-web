# Pellisoft — Web Design Specifications
## Especificaciones técnicas y funcionales del diseño web

---

## 1. Objetivo del sitio web

La web de Pellisoft tiene como objetivo principal:

- Presentar la empresa como **partner tecnológico serio**
- Comunicar **capacidad técnica real** (MES, SaaS, automatización)
- Generar **confianza B2B**
- Servir como **canal de captación comercial**
- Escalar a futuro como base para productos SaaS

El sitio **no es una demo de producto**, sino una **web corporativa premium con lenguaje tecnológico**.

---

## 2. Concepto visual global

**Estilo:**  
Industrial Tech · Dark Mode · SaaS Premium · Editorial tecnológico

**Principios clave:**
- Menos elementos, más intención
- Branding protagonista (no UI de producto constante)
- Movimiento sutil y continuo
- Dark mode como base
- Alto contraste y legibilidad

---

## 3. Paleta de color (sistema)

### Colores principales
- Azul Tech (marca principal)
- Negro Carbón (fondos)
- Blanco (tipografía primaria)

### Colores secundarios
- Morado Tech → innovación, producto, CTAs
- Verde Encina → identidad, ADN, storytelling
- Arcilla Teruel → acento narrativo puntual

**Regla:**  
El verde y la arcilla **no deben dominar la UI principal**.

---

## 4. Tipografía

### Tipografía principal (logo y titulares)
- Estilo: Tech‑Geometric
- Uso: H1, H2, claims, hero

### Tipografía secundaria (texto y UI)
- Estilo: Sans moderna (Inter / Manrope)
- Uso: párrafos, formularios, navegación

### Jerarquía
- H1 muy dominante
- Párrafos cortos
- Mucho espacio vertical

---

## 5. Estructura general del sitio

### Páginas principales
- Home
- Servicios
- Proyectos / Casos
- ADN Pellisoft
- Contacto

---

## 6. Home — Arquitectura UX/UI

### 6.1 Hero Section (Banner principal)

**Objetivo:** Impacto + posicionamiento inmediato

**Contenido:**
- Claim principal:
  > Software industrial y empresarial diseñado para escalar
- Subclaim:
  > Sistemas MES, SaaS y automatización desde Teruel para el mundo
- CTA primario: Hablar con Pellisoft
- CTA secundario: Ver proyectos

**Elemento visual:**
- “P” de Pellisoft abstracta
- Nodos, órbitas y líneas de datos
- Gradiente azul → morado
- Animación continua muy lenta

**Animaciones:**
- Entrada con fade + slide suave
- Capas que aparecen secuencialmente
- Movimiento idle sutil (respiración)

---

### 6.2 Sección Servicios (Bento Grid)

**Estructura:**
- Tarjetas modulares
- Iconografía lineal
- Borde sutil con glow al hover

**Servicios:**
- Sistemas MES Industrial
- Facturación SaaS / TPV
- Automatización e Integraciones

**Interacción:**
- Hover con ligera elevación
- Glow controlado
- Micro-animación de icono

---

### 6.3 Sección “Cómo trabajamos”

**Objetivo:** Generar confianza

**Flujo:**
1. Análisis
2. Diseño
3. Desarrollo
4. Escalado

**Estilo:**
- Visual limpio
- Sin animaciones complejas
- Transición al hacer scroll

---

### 6.4 Proyecto / Caso destacado

**Objetivo:** Demostrar capacidad técnica

**Visual:**
- Dashboard industrial (MES)
- Métricas, gráficas, flujos

**Regla clave:**
- Mostrar **1 caso potente**
- No saturar con múltiples dashboards

---

### 6.5 Sección ADN Pellisoft

**Mensaje:**
> Desde Teruel, para el mundo

**Diseño:**
- Sección editorial
- Gran “P” de fondo
- Verde encina oscuro
- Parallax suave

**Función:** Humanizar la marca sin perder profesionalidad

---

### 6.6 Contacto — Command Center

**Concepto:** Centro de control / terminal

**Diseño:**
- Glassmorphism oscuro
- Inputs con líneas base
- Cursor tipo terminal
- Glow sutil activo al focus

**Formulario:**
- Nombre
- Empresa (opcional)
- Email
- Proyecto

**Micro-interacción de envío:**
- Botón se transforma en barra de carga
- Mensaje final:
  > Conexión establecida. Nos pondremos en contacto desde Teruel.

---

## 7. Animaciones y transiciones

### Principios
- Nada brusco
- Nada constante que distraiga
- Animaciones con sentido funcional

### Tipos permitidos
- Fade
- Slide
- Scale suave
- Parallax lento
- Glow reactivo

### Tecnologías recomendadas
- Framer Motion
- CSS animations
- (Three.js solo si es imprescindible en hero)

---

## 8. Responsive y accesibilidad

- Diseño mobile-first
- Hero simplificado en móvil
- Animaciones reducidas en dispositivos low-power
- Contraste AA mínimo
- Textos legibles siempre

---

## 9. Stack tecnológico recomendado

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Hosting: Vercel

---

## 10. Principios finales de diseño

- Branding > decoración
- Claridad > espectacularidad
- Tecnología visible, no agresiva
- Escalable a SaaS y producto
- No parecer plantilla
- No parecer demo

---

## 11. Resultado esperado

- Web corporativa premium
- Imagen de empresa tecnológica real
- Alta confianza B2B
- Base sólida para crecimiento futuro
