# Pellisoft — Agents & Roles
## Agentes funcionales para el desarrollo de la web corporativa

Este documento define los agentes (roles) necesarios para diseñar, construir y mantener la web de Pellisoft.  
La arquitectura está pensada para un **proyecto frontend moderno**, con alto peso en **branding, diseño UI y experiencia visual**, optimizado para rendimiento y escalabilidad.

---

## 🧠 Agent 01 — Software Architect (Frontend)

**Rol principal:**  
Definir la arquitectura técnica y estructural del frontend.

**Responsabilidades:**
- Definir la arquitectura de la web (Next.js / React)
- Decidir estructura de carpetas y componentes
- Garantizar escalabilidad y mantenibilidad
- Definir patrones de renderizado (SSR / SSG / ISR)
- Asegurar buenas prácticas técnicas

**Output esperado:**
- Estructura del proyecto
- Decisiones técnicas documentadas
- Base sólida para crecimiento futuro

---

## 📊 Agent 02 — Functional Analyst (UX / Business)

**Rol principal:**  
Traducir objetivos de negocio y marca en funcionalidades claras.

**Responsabilidades:**
- Definir arquitectura de información
- Priorizar secciones y contenido
- Alinear UX con objetivos comerciales
- Validar que la web comunica confianza B2B
- Definir flujos de navegación

**Output esperado:**
- Estructura UX clara
- Flujos de usuario definidos
- Reglas funcionales de la web

---

## 🎨 Agent 03 — Web Designer / UI Expert

**Rol principal:**  
Diseñar la identidad visual y la interfaz de usuario de la web.

**Responsabilidades:**
- Diseñar el estilo visual global de la web
- Traducir el branding de Pellisoft a UI real
- Diseñar hero sections, banners y layouts
- Definir tipografías, colores y jerarquías
- Diseñar componentes UI (cards, botones, formularios)
- Definir animaciones y transiciones visuales
- Garantizar coherencia visual en todo el sitio

**Foco principal:**
- Branding tecnológico
- Estética premium
- Claridad visual
- Experiencia moderna
- Diferenciación frente a webs genéricas

**Output esperado:**
- Dirección creativa clara
- Diseño visual consistente
- Bocetos / wireframes / referencias
- Base sólida para implementación frontend

---

## 💻 Agent 04 — Frontend Expert (UI Engineer)

**Rol principal:**  
Implementar el diseño visual y la experiencia de usuario en código.

**Responsabilidades:**
- Construir componentes UI reutilizables
- Implementar layouts responsive
- Aplicar animaciones y micro‑interacciones
- Traducir fielmente el diseño a código
- Optimizar rendimiento y accesibilidad

**Stack habitual:**
- React
- Next.js
- Tailwind CSS
- Framer Motion

**Output esperado:**
- Interfaz funcional y fluida
- Código limpio y mantenible
- UI consistente con el diseño

---

## 🧪 Agent 05 — Tester (Frontend)

**Rol principal:**  
Detectar errores funcionales y visuales.

**Responsabilidades:**
- Probar navegación y flujos
- Validar responsive
- Revisar animaciones
- Detectar bugs visuales
- Probar en distintos dispositivos y resoluciones

**Output esperado:**
- Lista de errores y mejoras
- Feedback claro para correcciones

---

## ✅ Agent 06 — QA (Quality Assurance)

**Rol principal:**  
Garantizar la calidad final y percepción profesional.

**Responsabilidades:**
- Revisar coherencia visual global
- Validar copy y textos
- Verificar accesibilidad básica
- Evaluar tiempos de carga
- Comprobar sensación final de marca

**Output esperado:**
- Web lista para mostrar a clientes
- Imagen profesional sólida
- Sin errores visibles

---

## ☁️ Agent 07 — DevOps (Frontend‑focused)

**Rol principal:**  
Asegurar despliegue limpio, rápido y estable.

**Responsabilidades:**
- Configurar entorno de despliegue
- Optimizar build
- Configurar hosting
- Control de versiones
- CI/CD básico

**Stack habitual:**
- Vercel
- Git
- GitHub

**Output esperado:**
- Despliegue estable
- Buen rendimiento
- Cero fricción técnica

---

## 🔄 Orquestación de agentes

Flujo recomendado:

1. Functional Analyst define objetivos y estructura
2. Web Designer define estilo visual y UI
3. Software Architect define arquitectura técnica
4. Frontend Expert implementa la interfaz
5. Tester revisa funcionalidad
6. QA valida calidad y percepción
7. DevOps despliega

---

## 🧩 Nota importante

Estos agentes:
- Pueden ser ejecutados por una sola persona
- Pueden apoyarse en Copilot / IA
- Están pensados para crecer a futuro sin rehacer el sistema
