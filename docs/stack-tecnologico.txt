1. El Stack Tecnológico: Next.js + Tailwind CSS + GSAP
Framework: Next.js (React)
Es el estándar de la industria para aplicaciones web modernas por varias razones:

Rendimiento (Core Web Vitals): Al ser una empresa de software, tu web debe cargar instantáneamente. Next.js permite el renderizado híbrido (SSG/SSR), asegurando que la primera pintura sea casi inmediata.

SEO Técnico: Fundamental para que Pellisoft aparezca en búsquedas de "software industrial" o "SaaS factura".

Estilizado: Tailwind CSS
Para lograr la paleta de Negro Carbón, Verde Encina y Arcilla con precisión quirúrgica:

Consistencia Visual: Permite definir un sistema de diseño (tokens) para que todos los bordes, sombras y efectos de glassmorphism sean idénticos en toda la web.

Optimización: Solo carga el CSS que realmente se usa, manteniendo la web ligera.

Animaciones: GSAP (GreenSock Animation Platform)
Aquí es donde ocurre la magia de las transiciones que pediste:

Control Total: A diferencia de las animaciones CSS simples, GSAP permite encadenar movimientos complejos (como los hilos de datos en la sección MES) con una suavidad profesional.

ScrollTrigger: Para que los elementos aparezcan o se muevan (parallax) exactamente cuando el usuario hace scroll, creando esa experiencia inmersiva.

2. Infraestructura y Despliegue (DevOps)
Hosting: Vercel o Netlify. Ofrecen despliegue continuo (cada vez que haces un cambio en el código, se actualiza la web) y una red de entrega de contenido (CDN) global, para que tu web vuele tanto en Teruel como en Tokyo.

Backend para el Formulario: Resend + React Email. Para que cuando alguien use el formulario de contacto, recibas un correo con un diseño tan limpio como la propia web.

3. ¿Por qué esta elección?
Un arquitecto elige tecnologías basándose en escalabilidad y mantenimiento. Con este stack:

Es escalable: Si mañana decides añadir un panel de cliente para tu software de facturación, la base ya está lista.

Es "Future-proof": No tendrás que rediseñar la arquitectura en 5 años; estas tecnologías son el presente y futuro del desarrollo web.

Refleja el Producto: Un cliente que ve una web que se mueve a 60fps con transiciones de alta gama confía en que tu sistema MES tendrá la misma calidad.
